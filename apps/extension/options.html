MTK RADAR AI — Save Page settings

The API URL points at your MTK RADAR API. The token is the DEDICATED, intake-only extension credential (MTK_EXTENSION_TOKEN) — NOT the shared API/service token. It can only save candidate items (POST /items) and identify itself; it cannot read private media, run jobs, or delete anything. Ask your deployment operator to mint one and rotate/revoke it (change the MTK_EXTENSION_TOKEN env) whenever the browser profile should lose access — it takes effect immediately.

MTK RADAR AI — Save Page settings

The API URL points at your MTK RADAR API. The token is the DEDICATED, intake-only extension credential (MTK_EXTENSION_TOKEN) — NOT the shared API/service token and never a personal reviewer token. It can only save candidate items (POST /items) and probe its own identity (GET /whoami); it cannot read private media, run jobs, or delete anything. Ask your deployment operator to mint one; rotating or revoking it (change MTK_EXTENSION_TOKEN) cuts off this browser profile immediately.
